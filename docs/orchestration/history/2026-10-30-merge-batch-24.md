## What changed and why

Three branches, one product file between them, and nothing else in the
batch touches it. The batch moves no milestone: it closes one defect in
`herd-runner` and turns two published claims from assertions into
measurements, which is the half of invariant 5 that prose can carry.

`herd-runner/src/cgroup.rs` stops inferring a controller from a file.
`Ceiling::prove_io_max` decided whether the `io` controller had been
handed down to a job's cgroup from whether `<probe>/io.max` **existed**,
and a file proves nothing about a controller: PSI files are not
controller-gated, and `app.slice` on this host holds `io.pressure` while
`io` is absent from its `cgroup.controllers`. It now reads
`<probe>/cgroup.controllers` before it writes anything, and the write is
left to answer only the kernel's own two readings — `ENOENT` on the
interface file is a kernel with no blk-throttle, any other error is the
device refused. So three hosts get three sentences where two of them
shared one that named both causes and neither answer (**D265**).

Two figures the project published are now measured, and both came out
**narrower than their names**. Invariant 2's *"≤ 5 s"* had never been
timed against a running runner; it is **0.212 s** from SIGTERM to
process exit, a 24× margin, and **idle** — `0 job(s) to end` is the
whole scope, so the draining path with work in flight, which is the case
the bound exists for, is still an assertion (**D264**, **ORCH-280**).
And `bytes_written` in a job record, with the disk cap enforced against
it, is the **apparent size of the job's workspace, sampled**: an ad-hoc
job's build is not in the figure at all, a sparse file trips the cap
having written nothing, and the cap fires on whether a 200 ms poll
landed in a window (**D263**, **ORCH-278** for Alexa, **ORCH-279** for
the labelling half).

What `main` can do now that it could not before: refuse a hard
`--job-io-max` on a host whose kernel was never handed the controller to
enforce it with, instead of telling an operator a ceiling is enforced.
What it still cannot do is measure what a job wrote.
