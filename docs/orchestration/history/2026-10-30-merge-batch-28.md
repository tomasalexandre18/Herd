### Branch 1 — `settle-confinement-hollow`

**The hollow green is closed, and the method is the point.**
`a_job_cannot_hide_what_it_wrote_from_its_disk_budget` was a **counted,
hollow assertion**: it passed through Herd whether or not the product
behaviour existed. **Attribution by timing is impossible** — both
runners run the identical `mode | 0o700`, and only the enclosing one is
a prebuilt binary — so no amount of waiting distinguishes them.

The fix is an **enclosure**: the harness's data root sits inside a
directory the test keeps, and because restoration walks **ancestors
first**, the enclosing runner cannot restore the hidden directory
without restoring the enclosure in the same call, which **signs** it.
The verdict is **three-way, not a boolean**: the premise held, something
outside opened it, or it was never set.

**Proved both ways**, each in its own Herd job so no output was
coalesced: the **old** test **green** under the mutation (`j0000000160`,
3 of 3 — the hollow green demonstrated, not argued); the **new** one
**red 3/3** with `restore_access` robbed of its effect (`j0000000160`
for the old, `j0000000159` the negative control) and **green 3/3** alone
and **10/10** whole-file (`j0000000158`, `j0000000162`).

**The guard's own reliability is measured, not asserted:** ten
judgements cost **twelve attempts**, **two void**, about **17 % per
attempt**, worst run 2 of its 8; eight attempts give a margin of roughly
**7e-7**. **No product change**, and the mutation was reverted inside
its own job.

**And one finding, code-read and deliberately not run.** Restoration
covers a directory that cannot be **listed**; **nothing** covers one
that lists but cannot be **searched** — `measure_tree`'s
`entry.metadata()` returns `Err` with no restoration — so a job can
defeat its own disk measurement with a mode nobody planned for, and it
then ends on a sentence blaming the **operator** for a mode the **job**
set. Its author did not test it, and said why: a nested test would make
its own enclosing Herd job unmeasurable and kill the gate run it is part
of. **That labelling is kept: a code reading, not a measurement.** It is
ORCH-303.
