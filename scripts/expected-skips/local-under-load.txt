# on 2026-10-28, host=servernixos nproc=12 load1=9.56 at step 0 and 14.91
# at the end, sha=7403626307a2d3ad621c35656b3742877c12fc4f, suite 257 s,
# `test suite: PASSED`, 14 HERD-SKIPPED lines. These are the two of those
# 14 whose names are not in local.txt (12 at rest), so the list grows by
# exactly the two load-gated flood benches and by nothing else — no
# cgroup refusal moved, which is what makes the pair readable.
#
# Why these two lines were selected from that blessed run rather than
# written by --bless itself: --bless only ever writes $HERD_GATE_EXPECTED

# but there is no mode that writes this file. Blessing straight into
# local.txt from a loaded run would put all 14 there and an at-rest run
# would then pass with a flood bench silently skipped. The delta is the
# honest shape, and it is the shape README.md documents.
